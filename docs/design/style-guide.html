06 · 使用边界

Do & Don't

两套皮肤隔离维护，交互原语与令牌边界以 DESIGN.md 为准。

Do

  • post 皮肤在 post.css 顶部声明 @layer ui-sdk;，所有交互组件从 @ui-sdk/react/* 独立入口导入。
  • post 控件统一使用 preset b1ZjA4vKa（taupe + 皇家蓝）语义变量与 lucide-react 矢量图标，保证浅色与深色模式正文对比度 ≥ 4.5:1。
  • post 保持 15px / 24px 微博阅读字号与 QuoteFallback 引号字体栈。
  • chat 皮肤保持原有 Aero 标题栏渐变、琥珀激活条与三级投影，不被 post 改动波及。
  • 桌面最小视口维持 900×560，三栏与弹窗均不横向溢出。

Don't

  • 不要在 chat.css 与 post.css 之间共享或混用令牌；两份样式表各自通过边界检查。
  • 不要在 post 中重新引入星空壁纸、彩色系统 emoji 装饰、纸面点阵或硬偏移投影。
  • 不要在已有 UI SDK 组件时手写 role="dialog"、role="listbox" 等自定义交互。
  • 不要为 post 引入全局 CSS Reset 框架导致 chat 样式泄漏。
