# post 星空皮肤改为无 banner 的三栏布局

2026-10-18，用户在本次对话中确认调整星空皮肤：移除顶部品牌 banner（微博标志、“微博”字样与“随时随地发现新鲜事”），页面顶部只保留 32px 星空留白；微博群聊切换按钮与高级搜索同排在正文标题栏右侧。

主体改为三栏：博主管理在左，微博流居中，日期面板仍在右侧并与正文顶部对齐。此决定替代 ADR-0009 中的 112px banner、左侧微博流＋右侧工具栏以及右栏“日期选择 → 博主管理”排列；日期算法、读取范围、同步与登录恢复逻辑不变。

所有文字操作按钮统一在左侧使用 emoji 图标，按钮内文字左对齐；日期格数字垂直居中，圆点仍固定在底部。窄窗口三栏收为 220px／自适应／240px，图片格在空间不足时等比缩小，保持不横向溢出。
