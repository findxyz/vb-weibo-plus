# 本地微博采用星空双栏与方格日历

2026-10-18，用户在本次对话中确认以最后一张星空效果图调整 post 页面。此决策替代 ADR-0006 中的三栏布局与日期树；不改变现有阅读查询及采集边界。

页面最大宽为 1120px，左侧连续微博流，右侧日历在上、博主管理在下。顶部增加与星空融合的微博标志和“随时随地发现新鲜事”。正文继续使用现有字体和 15px／24px 字号，转发为 14px／24px。元信息移动至正文后方，仍仅提供查看原文。

日期树改为星期一开头的方格月历，年份与月份可直接选择，也可前后月导航。无内容日期禁用，有内容日期显示圆点。导航月份只改变本地界面；点击有效日期仍使用当前上海时间日界限读取该日全部微博。切换博主回到最新有效日；高级搜索定位自动显示目标年月。

同步历史按钮常驻于添加按钮旁。全部博主状态使用原生 disabled，选中单个博主后启用；进行中的任务继续保持防重与提交时范围快照。后台采集、读取接口和扫码恢复逻辑不变。

双栏让正文从左边开始，接近参考图；代价是日期和博主共享右侧高度。右栏整体可滚动，博主列表另有限高，保证 900×560 窗口也能访问全部操作。chat 皮肤保持不变，post 的新令牌统一记入 DESIGN.md，旧几何基准保留为迁移存档，不通过重录覆盖。
