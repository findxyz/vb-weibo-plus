# 本地微博页面改为三栏布局，日期时间轴取代筛选栏与分页

参考 weiboblog 的「左侧日期树 + 右侧 feed」导航方式，本地微博页面从两栏（博主面板 + feed 筛选栏分页）改为三栏：博主列表（含「全部博主」行）280px、日期时间轴 200px、右侧 feed。原有顶部筛选栏（起止日期/关键词/查询/重置）与底部分页移除，关键词搜索改由 feed 头部的「高级搜索」浮层承担。点击日期树某日后，feed 一次加载该日全部微博（复用 `/post/list` 传 start/end + 大 size，无分页），月份/日期切换成为主要导航。日期树后端由新增的 `GET /post/calendar` 单端点提供聚合，选「全部博主」时聚合全部博主。
