# Chat.js 模块化决策

将分析、历史、庆祝、编辑器与媒体发送、群列表和当前消息会话拆为独立模块。入口仅负责当前群、模块组装、登录、初始化、页面可见性与刷新调度；消息 Map、游标、跟随状态和消息 DOM 由当前会话模块独占，跨群回调一律携带所属群。模块通过工厂参数与回调协作，不新增后端协议。

已验证：`mvn test` 通过，群聊 UI 定向回归通过，各模块通过 `node --check`，`mvn package` 通过。完整群聊组合路径（选群、滚动、媒体、历史、分析、发送、庆祝）与扫码重初始化去重已由集成测试覆盖，打包资源经临时目录启动 jar 并逐项核验本地 HTTP 状态与 MIME，全量 390 个测试通过。

测试侧直接覆盖 `spring.datasource.url` 隔离真实库与 cookie（实测确认 yml 中的 `${weibo.database-path}` 占位符在测试环境不采纳测试侧覆盖），同步群号在测试中留空，不向真实微博发起请求。

输入法误发、刷新缺口和首屏失败恢复仍属于范围外问题。
