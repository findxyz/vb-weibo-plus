## 转发链 @用户名: 补链接（用户要求）
- 场景：微博正文 content 来自纯文本（textRaw / 长文 raw）时，转发链里的 `@用户名:` 是纯文本无链接，例如 `//@tombkeeper:今天的盲猜关注列表活动又开始啦！//@HyGPT:说的有错误？//@兽族家里有狼骑:...`。
- post.js 新增 `linkifyMentions(root)`，仿 `linkifyUrls` 的 TreeWalker + DocumentFragment 模式：遍历文本节点，跳过已在 `<a>` 内的（`closest("a")`），把 `@用户名` 包成 `<a href="https://weibo.com/n/用户名">@用户名</a>`，冒号及前后文本保持原样。
- 正则 `MENTION_RE = /@[A-Za-z0-9_\-\u4e00-\u9fff]+(?=:)/g`：用户名字符为字母/数字/下划线/连字符/基本区中日韩汉字，lookahead `(?=:)` 确保用户名后紧跟英文冒号才匹配，不消费冒号。这样普通 `@用户名 `（后跟空格）与邮箱 `user@host.com` 不被误处理；全角冒号「：」不触发。
- `renderContent`（post.js:836）在 `linkifyUrls(doc.body)` 之后加 `linkifyMentions(doc.body)`，置于已有 `<a>` href 修正循环之前——新生成的 mention `<a>` 会被后续循环统一加上 `target="_blank" rel="noopener"`（其 href 是完整 `https://` 开头，不进相对地址补全分支）。
- CSS 无需改动（`.post-content a, .post-retweet-content a` 已统一样式）；正文与转发块都经过 renderContent，均生效。
- 边界已用 node 脚本验证（多级转发链、中文用户名、冒号保留、邮箱不误匹配、无冒号不匹配、连字符用户名、全角冒号不触发、已有 `<a>` 内 @ 不重复处理）；PostPageTest 测试数据无 `@xxx:` 模式，断言用 containsText，不受影响。
