## 群聊分析改为 SSE 流式输出
- AiClient 新增 `chatStream(userPrompt, deltaConsumer)`：java.net.http.HttpClient 调 OpenAI 兼容接口（stream:true），逐行解析 `data:` SSE 帧取 `choices[0].delta.content`，回调增量并拼全量返回；抽出 chatUrl/chatRequestBody 共用
- AnalysisService 抽出 prepare/save（私有 record PreparedAnalysis），新增 `analyzeStreaming`；原 `analyze` 保留
- AnalysisController 新增 `POST /chat/analyses/stream` 返回 SseEmitter（超时 = weibo.ai.timeout-seconds + 60s），CompletableFuture 异步执行；事件：delta（增量文本）/ done（AnalysisView JSON）/ error（错误消息）
- 前端 submitAnalysis 改 fetch + TextDecoderStream 手解 SSE（EventSource 不支持 POST），边收 delta 边 marked 渲染到详情区并滚底；done 后刷新列表并展示最终详情；失败回退到列表 + feedback
- 已验证 Spring 6.2 SseEmitter 会把多行字符串 data 拆成多条 data: 行（writeStringData），前端按行 join("\n") 解析与其匹配
- 注意：Java 改动需用户 IDE 重新构建后生效；chat.js 已同步 target
