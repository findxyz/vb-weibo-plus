
## post/index.html 前端优化
- 视频卡片仅在同时有 pageUrl + coverUrl 时展示（hasPlayableVideo），无视频地址不再显示封面图
- 播放三角从 ▶ 字符改为 CSS border 绘制，保证在圆形按钮正中
- 三个面板标题统一为 15px/600、头部高度统一 48px，辅助信息统一 12px muted
- 字体栈从 Tahoma 换为 PingFang SC / 微软雅黑 / Noto Sans CJK 等系统阅读字体，加抗锯齿
- 数字用 tabular-nums 对齐，去掉错误红字闪烁动画，图片加悬停变暗反馈

## post 页第二轮优化
- 外层视频与转发视频 pageUrl 相同时只保留转发中的，避免重复展示
- renderContent 改用 DOMParser：相对链接（@ 用户的 /n/xxx）补全为 https://weibo.com，协议相对链接补 https，统一 target=_blank
- 去除转赞评数据，仅保留「查看原文」链接；转发正文字号 14px → 15px
- 注意：库里 @ 用户链接是无引号的相对地址 href=/n/xxx，直接点击会跳到 localhost
