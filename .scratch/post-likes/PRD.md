# 本地微博点赞

Status: implementing

## 已确认范围

- 当前微博账号真实点赞与取消点赞，仅针对外层微博；转发卡片操作转发帖自身。
- 前端只调用本地 `/post` 业务入口；`PostService` 直接复用微博 API 适配类。`/weibo` 提供测试入口，示例分别写入 `POST_API.http`、`WEIBO_API.http`。
- 微博进入可见区域时查询本人已赞状态与当前总数，同一次浏览避免重复请求；状态未知时显示重试入口，不视为未点赞，也不显示旧计数。
- 等待远端确认后更新按钮，操作期间禁用；写请求超时或结果不确定时通过只读查询核对，禁止自动重发写请求。
- 互动数据仅作为当前页面会话状态，不覆盖首次采集的微博内容与计数。重新扫码登录后清理本人互动缓存。
- 微博风控要求验证时提示前往微博网页版处理，不伪装成功。

## 实现与验收

1. 在 `/post/like` 提供独立状态查询与显式目标状态写入，按本地 `mblogId` 解析外层数字 ID。验证：经真实 Controller、Service、API 和 HTTP 客户端，模拟微博响应，覆盖未知本地微博、异常响应与已赞状态缺失。
2. 为可见卡片添加按钮与当前计数。验证：浏览器测试覆盖可见范围查询、缓存、点赞与取消、等待状态、未知状态重试、失败及结果核对、重新登录缓存清理。
3. 补测试入口与接口文档。验证：后端测试、前端类型检查与构建、浏览器测试、改动审查。

一方证据见 `docs/research/weibo-post-likes.md`。自动测试不操作真实账号的点赞状态。
