# 23：chat 群列表搜索与元数据刷新

**What to build:** 侧栏群列表显示每个群的最新消息预览，支持本地关键字过滤；群元数据随轮询刷新，人数与消息数、预览和头像保持在当前群上更新，不打断会话与滚动。

**Blocked by:** 22，已完成。

**Status:** resolved

日期：2026-10-17。用户要求继续下一票。本票只做本地列表与元数据，不新增群、不调用微博接口、不写库。

## 实施边界

### 列表与搜索

- 每行显示头像、群名与预览：有最新消息时为 `发送者：内容`（只有内容则只显示内容），否则退回 `N 人群`。
- 行按钮的 `aria-label` 为群名与预览，选中行带 `aria-current`。
- 侧栏标题「群聊列表」，计数为 `N 个群聊`；无数据时显示「暂无群聊数据」。
- 搜索框本地过滤，忽略大小写，匹配群名与预览文本；被过滤掉的行用 `hidden` 隐藏、不可聚焦；清空后恢复。不因输入发起请求。

### 元数据刷新

- 群列表与消息轮询同节奏刷新（约 1 秒），同一时刻只保留一个在途请求；页面隐藏时不刷新，回到页面立即刷新一次。
- 刷新后当前群的人数、消息数、预览、头像与管理员名单更新；选中的群、会话消息与滚动位置保持不变。
- 后台刷新失败时保留上一次成功的列表，不用错误面板替换；恢复后自动更新。首次加载失败仍显示失败提示与重试。

## 验收标准

- [x] 列表按旧页格式显示预览与 `aria-label`；无消息的群显示人数；计数与空状态文案正确。
- [x] 搜索按群名／预览过滤且忽略大小写，隐藏行不可聚焦；清空恢复；过滤不改变当前群、消息与滚动位置。
- [x] 约每秒刷新群列表并去重；当前群的消息数、预览与管理员在刷新后更新，选中态与滚动不变。
- [x] 刷新失败保留旧列表且不显示错误面板；恢复后更新；首次加载失败仍可重试。
- [x] 页面隐藏期间不刷新群列表；回到页面立即刷新一次。
- [x] 全程无业务写请求；旧正式 chat 与 React post 回归、构建资源检查保持通过。

### 实现

- `GroupList.tsx` 增加搜索框与本地过滤：忽略大小写匹配群名与预览，命中之外的行加 `hidden`（配合 `.group-row[hidden]` 不可见也不可聚焦）；标题改回「群聊列表」，计数 `N 个群聊`，空状态「暂无群聊数据」。
- `display.ts` 增加 `groupPreview`，口径与旧 `groups.js` 一致：`发送者：内容`，无发送者只显示内容，都没有退回人数；行的 `aria-label` 为群名与预览。
- `ChatPage.tsx` 的群列表查询改为约每秒刷新（`refetchInterval: 1000`、页面隐藏时暂停），窗口重新获得焦点时立即刷新；`refetchOnMount: false` 与 React Query 的在途去重保持不变。
- 后台刷新失败时保留上一次成功的列表：只有「从未成功过」才显示失败面板与重试；当前群的人数、消息数、预览与管理员随刷新更新，选中态、消息与滚动位置不变。
- `chat.css` 增加搜索框样式与 `--search-border`／`--search-bg` 令牌，侧栏改为标题、搜索、列表三行。
