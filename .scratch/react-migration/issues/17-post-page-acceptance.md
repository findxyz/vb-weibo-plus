## 范围与成功标准

依据旧 post/index.html、post.js、bloggers.js、dates.js、posts.js、viewer.js、共享登录／通报工具、PostPageTest、DESIGN.md 及任务 03 至 16。按验收矩阵覆盖入口导航、阅读、文本／媒体、搜索、登录、管理和采集；组合路径覆盖状态保持、异步隔离、键盘、长列表、最小桌面与生产资源。保持既有接口和同 JAR 发布，不新增依赖、后端或功能。

发现的迁移缺陷单独记录、先复现再最小修复并独立提交；与整页迁移无关的问题不顺带修改。明确保留已确认差异：头像／正文 CDN 图片代理、媒体失败可用占位、安全清洗、纸感遮罩／投影、减少动态效果及异步操作隔离。

新增入口仍指向旧正式 chat，开发时使用配置的后端 URL，生产使用同源 /chat/index.html；不会误跳到 chat 骨架。保留预览标题和旧 post 对照入口，正式入口切换与旧源码清理留给 18。

| --- | --- |

## Acceptance criteria

- [ ] 矩阵各能力有源码／既有或新增浏览器行为证据；迁移遗漏均复现并修正，无未解决阻断项。
- [ ] 至少一条跨功能用户路径贯穿过滤／日期／搜索定位／图片／登录恢复／添加／采集，业务写请求只用本地替身。
- [ ] 三个桌面尺寸、键盘／模态／阅读摘要、长列表与组合样式通过；对照截图人工检查，已知差异明确。
- [ ] 前端全套与类型／构建、干净 Maven verify、最终隔离 JAR 及资源 MIME 通过；独立 Standards／Spec 审查完成。
- [ ] 发布包／哈希、迁移地图和验证限制完整，正式入口与旧 chat 不切换。

## 验证隔离

不执行真实扫码、群同步、添加或微博采集。浏览器业务写及登录检测使用本地替身；JAR 使用临时 SQLite、缺失 Credential 与空自动采集群号。保持用户服务，禁止输出运行中 Java 参数或配置中的秘密。复查既有 worker 原生退出问题，按实测结果记录，不用自动重试隐藏失败。
