# 16：React post 按时段采集历史博文

**What to build:** 迁移单博主“同步历史”入口、日期范围弹窗、后台请求反馈及完成后的日期刷新。

**Blocked by:** 15，已完成。

**Status:** resolved

日期：2026-10-17。用户授权本批连续完成至此票，任务 17／18 不在本批实施范围。

依据旧 bloggers.js／index.html／post.css、POST /post/range、PostPageTest 与共享日期工具。仅选中具体博主时显示入口，打开显示当前 @名称，开始为上海今天向前 24 个月（跨月按共享规则收敛），结束为上海今天；每次重开重置日期／错误。开始、结束均必填且开始不晚于结束，支持同日；取消、Escape 与点击遮罩不提交，键盘可用。

有效提交立即关闭弹窗，按提交时 UID、起止日期快照 POST /post/range，上海边界 00:00:00／23:59:59，沿用 15 秒 HTTP 超时。等待时全页只能有一项本页面发起的采集请求，不可重复提交或重开。保留旧提示：已存在的数据会跳过，范围越大耗时越久，若服务端已有任务则本次可能跳过；不声称客户端关闭或超时能取消服务端任务，不自动重试。

成功后仅当原博主仍处于同一次访问时刷新其日历，并显示“同步完成”；刷新前固定已有阅读日期，不自动跳到新采集的最新日，不重新读取当前正文。原先没有有效日期时，沿用当前默认阅读路径，日历出现数据后进入最新有效日。用户切换范围后不刷新新范围、不显示原范围成功提示。只刷新日期失败时沿用日历错误，不重发采集 POST。

非 401 错误在主窗口右上角显示“同步历史微博失败：接口消息”，6 秒后隐藏，可重新打开后手动提交；401 使用统一扫码恢复，不显示重复错误。卸载清理请求与提示定时器；服务器采集生命周期保持后端原样。

复用 420px 纸感弹窗、已有日期输入／按钮／焦点令牌；遮罩使用纸感墨色，投影 shadow-card。成功日期状态为纸感铅笔色、12px 等宽数字。900×560 弹窗滚动可用，长博主名不撑破标题／日期。
