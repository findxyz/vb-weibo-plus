# 08：React post 图片查看器

**What to build:** 点击普通或转发图片打开原图查看器，保留旧版循环切图、键盘与关闭行为。

**Blocked by:** 07，已完成。

**Status:** claimed

日期：2026-10-14。用户已授权本票细化与实施。

## 范围与依据

依据旧 viewer.js、posts.js 的图片入口、post.css 的 image-viewer 规则、DESIGN.md 及现有浏览器测试。图片列表继续优先读取缩略图，只有打开或切到对应图片时读取原图；没有安全原图地址时回退到安全缩略图。复用票 07 的地址过滤，不新增接口、请求库或第三方依赖。

普通图片与转发图片分别形成当前图片组，点击第几张就从对应索引打开，不跨层或跨博文合并，不去重重复图片。地址缺失／非法的记录沿用票 07 过滤；缩略图失败而隐藏的记录仍属于该组，保持原有索引与计数语义。

图片入口成为可聚焦按钮，支持鼠标与 Enter／Space，保持旧版格子尺寸、纸感皮肤及焦点环。查看器使用原生模态 dialog，全屏纸墨遮罩、居中等比图片，按钮和计数与旧版一致；背景页不可点击，焦点限制于查看器。

多图显示上一张／下一张及“当前 / 总数”，首尾循环；左右方向键沿用同样规则。单图不显示切换按钮和计数。Esc 或点击查看器背景关闭，点击图片或切图按钮不关闭，不离开当前页面；关闭后焦点回到图片入口，阅读位置不变。

打开与切图显示“加载中…”，加载成功显示图片并清空状态，失败隐藏图片并显示“图片加载失败”。快速切图、关闭或卸载后，旧图片的晚到成功／失败不得改变当前图及状态；失败后仍可切换或关闭，重新打开可再读取。页面或 feed 卸载时清理原生 dialog，不保留全局键盘监听或轮询。

## Acceptance criteria

- [ ] 普通与转发图片从对应索引打开正确原图，缺少／非法原图回退缩略图；有缩略图时不开查看器不请求原图，不预取整组原图；重复与隐藏记录的计数语义保持。
- [ ] 多图按钮／方向键循环、单图控件隐藏、Esc／背景关闭、图片点击不关闭、键盘入口／焦点限制与恢复通过；关闭后 URL、阅读滚动、博主／日期状态保持。
- [ ] 加载／失败及快速切图的晚到事件隔离、关闭后重开与组件卸载通过，无业务写请求或非预期浏览器异常。
- [ ] 同数据旧版与 React 查看器布局／纸感样式对照，前端全套检查、类型与双入口构建、Maven 资源检查及独立 JAR 读取／切图通过；审查、地图与发布证据完整。

## 实施与验证

继续使用已确认的浏览器 UI／本地 HTTP fixture 边界做逐切片验证，先打开原图与关闭，再接切图，随后补加载竞态与视觉对照。查看器状态由当前 PostFeed 持有；展示组件负责原生 dialog 生命周期和当前图片，不把状态抬到查询缓存或全局。

构建在独立 worktree 完成，定向验证 ReactPreviewPageTest。独立 JAR 使用隔离 SQLite、缺失 Credential、空采集群号与本机图片 HTTP 上游，验证真实图片接口，不请求外部微博媒体或业务写接口。正式 post／chat 与运行中的旧 JAR 不切换。

## 范围外
