# 19：React chat 消息窗口、动态高度与滚动锚点

**What to build:** 打开 chat 预览后载入上次选择（或第一个）群的最新一页消息并停在底部；向上滚动时连续加载更早消息且视口不跳；长会话用滑动窗口保持 DOM 规模有界；一次性落底之后，已存在消息的图片加载造成的撑高在收尾内补偿，收尾结束后任何内容增长都不再移动视口。

**Blocked by:** 18，已完成。

**Status:** resolved

日期：2026-10-17。用户要求开始 chat 第一票。本票只做消息窗口与滚动的最小闭环，其余会话功能仍按后续票迁移。

## 实施边界

### 数据与请求

- 群列表：GET /chat/groups。默认 gid 取 localStorage 中上次选择且仍在列表内的群，否则取列表第一个；选中后写回。列表为空显示空状态，不发起消息请求。
- 消息：GET /chat/messages/cursor。首屏 size=50、不带游标；向上翻页带 beforeCreatedAt 与 beforeMid；按响应中的 hasMore 与 nextBeforeCreatedAt／nextBeforeMid 决定是否继续。
- 排序与旧页一致：createdAt 升序，相等时 mid 升序。
- 本票不主动请求表态、历史、采集、登录与发送接口，不发起业务写请求，不启动轮询。

### 展示

- 蔚蓝拟物皮肤，令牌以 [DESIGN.md](../../../docs/design/DESIGN.md) 为准：38px 标题栏、280px 群列表侧栏、会话头、消息区独立滚动、最小窗口 900×560。
- 消息展示头像、发送者、时间与纯文本正文（保留换行）；系统消息用灰条、管理消息用暖黄变体；图片消息显示 previewUrl 缩略图，并隐藏「分享图片」「分享视频」「[动画表情]」这类占位文字。
- 群列表项只显示群名与头像（可含人数），不实现搜索、元数据刷新与未读统计。
- 本票不做链接化、表情贴图、文件、微博卡、视频、表态行与图片查看器；这些内容以可读文本降级，由后续内容票替换。

### 滚动与窗口

- 一次性落底（[ADR 0008](../../../docs/adr/0008-scroll-to-bottom-is-one-shot.md)）：打开页面、刷新、从列表选群都落到底部，不跨页面记录阅读位置。
- 收尾：落底动作发生后，动作之前已存在的消息因图片加载撑高时把视口补回底部；wheel、touchstart、pointerdown、keydown 任一用户输入或新消息追加即结束收尾，之后不再移动视口。
- 滑动窗口：DOM 只保留视口附近消息，视口上方与下方各保留约 180 条、总数上限 360 条；窗口外区间用估算高度（96px 加 16px 间距）占位撑起滚动条，渲染过的消息按实测高度回写；滚动落入未物化区间时一次定位到目标位置，不逐批渲染沿途内容。
- 翻页锚点：滚动到距顶部 120px 以内且 hasMore 时加载上一页；请求前记录首条可见消息的 mid 与屏幕位置，插入更早消息后按该 mid 恢复视口，不用 scrollHeight 差值代替。
- 并发与隔离：同一时刻只允许一个向上翻页请求；切换群时清空消息、占位、游标与收尾状态；旧请求、旧图片 load 结果不得修改新群界面。
- 本票不实现 20000 条内存裁剪与更早区间丢弃，后续票处理。

### 失败与空状态

- 群列表失败：显示可理解提示与重试入口，页面结构保留。
- 消息失败：保留当前群与失败提示；再次点击该群可重新加载（与旧页选择同一群一致），本票不引入轮询恢复。
- 群存在但无消息：显示空状态，不显示为加载失败。

## 验收标准

- [x] 打开预览自动选中 localStorage 上次群（不存在时第一个），列表选中态与会话头一致；只发一次群列表请求和一次无游标的最新消息请求，参数为 gid 与 size=50。
- [x] 消息按 createdAt、mid 升序渲染并停在真实底部；无群、空群、群列表失败、消息失败都有明确状态。
- [x] 首屏图片晚于落底加载完成时仍停在真实底部；滚轮输入后到达的图片加载不再移动视口。
- [x] 距顶部 120px 内触发上一页请求并携带 before 游标；插入后锚点消息的屏幕位置变化不超过 1px，重复触发不会并发两个请求。
- [x] 800 条消息时渲染的消息节点不超过 360 个，上下占位高度按实测回写；跨越未物化区间滚动后目标消息可见且位置正确。
- [x] 切换群或卸载后旧消息清空，旧响应与旧图片 load 不修改新界面。
- [x] 全程无业务写请求、无轮询；开发代理与生产构建路径都能加载页面。
- [x] 蔚蓝拟物关键几何与 DESIGN.md 一致：标题栏 38px、侧栏 280px、气泡 4px 圆角与 #a7bdcd 描边、消息区独立滚动；900×560 无横向溢出。
- [x] 旧正式 chat 的 82 项回归与 React post 回归保持通过，构建资源中的 chat 预览可加载。

## 实施与验证证据

日期：2026-10-17。

### 实现

- `ChatPage.tsx` 负责群列表查询、默认选群（localStorage 上次群，否则第一个）、选中重载与会话头；`GroupList.tsx` 负责侧栏与失败重试；`MessageList.tsx` 负责首屏读取、滑动窗口、占位高度、锚点翻页、一次性落底与图片撑高收尾；`MessageItem.tsx`、`Avatar.tsx` 负责消息与头像展示；`api.ts` 只保留请求与排序口径。
- 消息只请求 `/chat/messages/cursor`：首屏 50 条、无游标；向上翻页带 `beforeCreatedAt` 与 `beforeMid`。未加入轮询、发送、表态、历史、分析、登录与庆祝。
- 删除骨架 `ChatPreview.tsx`；Vite 代理由仅 `/chat/image` 扩展为 `/chat/(groups|messages/cursor|media|image)`，仍是精确路径，不放宽前缀。
