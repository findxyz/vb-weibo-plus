# 27：chat 聊天记录浏览与搜索

**What to build:** 从编辑器工具行打开独立的「聊天记录」窗口：按日期区间、用户与关键词查询本地群消息，分页浏览结果；点击结果查看目标消息前后的上下文，并可继续向上／向下翻阅。整个窗口只读，不影响当前会话。

**Blocked by:** 26，已完成。

**Status:** resolved

日期：2026-10-17。用户选择先做历史。本票只做历史浏览与搜索，历史采集（同步更早消息）另立一票。

## 实施边界

### 打开与筛选

- 编辑器工具行增加「📜 聊天记录」按钮，无选中群时禁用；打开时按上海时区重置筛选：开始日期为 3 个月前、结束日期为今天，用户与关键词清空，结果与上下文隐藏，提示「设置筛选条件后点击查询」。
- 筛选表单提交后按 `page=1&size=20` 请求 `GET /chat/messages`，参数为 `gid`、`start`、`end`、可选 `senderName` 与 `keyword`；日期串按后端约定拼成 `YYYY-MM-DD 00:00:00` 与 `23:59:59`。
- 窗口标题为「聊天记录 - 群名」；Escape、关闭按钮与外部遮罩都能关闭；切群时关闭并忽略旧响应。

### 结果与分页

- 结果行显示时间、发送者与摘要：视频为「[视频]」（含红包识别规则）、微博卡为「[微博]」、图片为「[图片]」，其余为正文或消息类型名；关键词在摘要中高亮。
- 分页显示「第 x / y 页，共 n 条」，上一页／下一页在边界禁用；翻页沿用当前筛选条件。
- 无结果、查询失败与初始状态都有明确文案；迟到响应不得覆盖新查询。

### 上下文

- 点击结果进入上下文：以目标消息为游标同时请求前后各一页（`size=50`），按时间排序展示，目标消息高亮；顶部／底部显示「没有更早消息／没有更新消息」。
- 滚动到顶部或底部附近时按游标继续加载，向上加载保持当前可见消息位置；「返回搜索结果」保留原页码与筛选。
- 上下文只读，不参与实时轮询、表态或新消息提示；图片与视频交互沿用消息组件，不改变当前会话。
