# 11：React post 博主名称过滤

**What to build:** 迁移左侧“搜索博主”输入框，只过滤已加载博主的可见行，保留当前阅读范围。

**Blocked by:** 10，已完成。

**Status:** resolved

日期：2026-10-16。用户要求继续 React 迁移，按演进地图推进本票。

## 范围与事实依据

依据旧 bloggers.js 的 filterBloggers、旧 index.html 的搜索框、post.css、DESIGN.md 纸感令牌和既有 PostPageTest。输入去掉首尾空格后，以不区分大小写的名称包含匹配过滤；中文、名称中的数字和标点按普通文本匹配，不按 UID 搜索，不解释正则或 HTML。

“全部博主”始终显示。标题人数继续显示全部已加载博主总数；无匹配时仅隐藏具体博主，不新增提示文案。清空或仅空白时恢复全部行，保留原顺序。过滤不修改博主选中状态、日期、右侧标题和正文，当前选中博主被隐藏时仍保持阅读范围；清空后选中样式恢复可见。

输入值是页面局部状态，匹配条件从该值和接口数据直接计算，不存第二份过滤结果，不使用 Effect 同步派生状态。保留各博主行及头像组件，只以 React 的 hidden 属性控制可见性，避免过滤引起失败头像重新加载。输入过程中不发起业务查询、不写后端、不轮询；仅显式选择博主／日期才沿用现有查询流程。输入可以先于博主数据到达，数据到达后应用当前条件；查询加载或失败状态保持原语义。

过滤条件在选择博主或“全部博主”后保持，选择操作的默认最新日期、请求取消与响应隔离继续由既有 useDefaultReading 处理。输入框具有“搜索博主”可访问名称，使用原生 search 输入，不新增快捷键或表单提交。Tab 可以到达“全部博主”及可见博主，隐藏行不参与键盘导航。

搜索框位于博主标题下、滚动列表上，沿用 54px 行、34px 输入、15px 字体、4px 圆角及纸感颜色、边框和硬投影。只让左栏成为标题／搜索框／列表三行，日期与正文布局不变；沿用可见焦点环，最小 900px 桌面窗口保持三栏独立滚动。
