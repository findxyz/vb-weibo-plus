# 31：chat 回归庆祝

**What to build:** 在群聊里把成员加入回归庆祝名单并设置沉默间隔：成员沉默后再次发言时，怪兽走到其头像旁戳破水泡，欢迎回归；名册与设置持久化在本地。

**Blocked by:** 30，已完成。

**Status:** resolved

日期：2026-10-18。用户要求继续。

## 实施边界

- 点击消息发送者昵称打开「回归庆祝」设置弹层；群头名册显示已加入成员（头像、昵称、移除按钮），点击昵称可再次打开设置。
- 设置：沉默间隔秒数（默认 30，最小 1，非法值回退），「🎉 加入庆祝名单」与「👋 移出庆祝名单」；已在名单时修改间隔立即保存。
- 存储：`weibo-chat:celebration-roster` 按群按成员保存 `{ name, avatar, interval }`；`weibo-chat:celebration-seen` 按「群:成员」保存最后发言时间。
- 回归判定：新到达消息按时间排序逐条处理；首次见到该成员时只建立基线，之后间隔达到设定值才触发；加入名单时先用当前已加载消息垫高基线，避免误触发。
- 表演：头像水泡漂浮，怪兽从舞台边缘走入、轻戳、戳破水泡（水珠四溅）、欢呼并骑乘雷欧飞离；台词「你终于冒泡了」「赶紧的一同拯救世界去」；动画对 `prefers-reduced-motion` 跳过；舞台尺寸不足时不表演。
- 切群、重新加载或关闭页面会取消在途表演并清空舞台；名册与设置切换群后各自独立。

## 验收标准

- [ ] 点击发送者昵称打开设置弹层，默认间隔 30 秒，可加入名单并在群头看到名册。
- [ ] 名册与设置刷新后保留；点击名册昵称可修改间隔或移出名单。
- [ ] 沉默满间隔的成员再次发言时触发怪兽表演（卡片、水泡、台词、跳过按钮）。
- [ ] 未满间隔或首次见到的成员不误触发；表演可跳过并清理舞台。
- [ ] 切群取消表演并切换名册；设置与名册按群隔离。
- [ ] 旧正式 chat 与 React post 回归、构建资源检查保持通过。

### 实现

- `celebration.ts`：名册与基线持久化、加入时按已加载消息垫高基线、新消息按间隔判定回归、怪兽表演（三种图集、canvas 逐帧、WAAPI 位移、水泡与飞溅、骑乘飞离、跳过与取消、`prefers-reduced-motion` 跳过）。舞台尺寸不足时不表演。
- `CelebrationPanel.tsx`：群头名册（头像、昵称按钮、移除）与设置弹层（间隔数字输入、加入／移出、固定定位在入口下方、点外部或 Escape 关闭）。
- `MessageItem.tsx` 把发送者昵称改为可点击按钮（title「设置回归庆祝」），`MessageList.tsx` 增加 `onLoaded`／`onArrivals`／`onMessages`／`onSenderClick` 回调，`ChatPage.tsx` 负责舞台、名册、弹层与切群取消。
