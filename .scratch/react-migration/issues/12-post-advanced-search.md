# 12：React post 高级搜索查询与结果

**What to build:** 迁移高级搜索弹窗，按当前博主范围、关键词与日期查询本地博文，展示安全的结果摘要。本票先交付查询和结果阅读，点击结果定位另列任务 13。

**Blocked by:** 11，已完成。

**Status:** resolved

## 范围与依据

依据旧 search.js、index.html、post.css、共享 date.js 与 PostPageTest。复用 GET /post/list，不改后端、数据库、开发代理或依赖。高级搜索入口位于 feed 标题右侧；使用原生 modal dialog，打开聚焦关键词，关闭按钮和 Escape 返回入口焦点。

每次打开重置关键词、结果和错误，默认开始 2010-01-01，结束为上海时区今天。范围提示为全部博主或当前 @名称，范围取自当前选择，不受左栏名称过滤影响。仅提交才查询，关键词 trim 后不能为空；开始、结束均非空时要求开始不晚于结束，空日期允许省略。

参数 keyword、page=1、size=1000；单博主追加 uids，全部不传。日期沿用共享函数形成上海时间起止字符串；请求超时 30 秒。等待时搜索按钮禁用并显示“搜索中…”，不重复提交。失败显示接口消息，可修改条件后或原条件重试，不自动重试、轮询或预取；关闭／卸载取消在途请求，重开不会接收旧结果。

结果保持服务端顺序，显示上海时间、作者与纯文本摘要。优先 contentRaw，否则从 content 提取文字；不渲染摘要中的 HTML、链接、图片或脚本。关键词忽略大小写，只高亮首处，前后各保留 30 个字符并按需加省略号；无命中显示前 80 字符，空正文不编造内容。高亮按提交时的关键词，而非等待过程中编辑的新输入。无结果显示“未找到匹配微博”；total>1000 提醒缩小范围，否则显示找到的总数。

本票结果为静态阅读条目，不展示无法工作的按钮或点击指针；任务 13 再接入定位操作。搜索不更改主页面的博主／日期／正文／滚动位置或左栏过滤条件。

外框沿用 520px、最高 80vh、标题 40px、输入 36px 与旧纸感几何，长结果在弹窗内滚动；900px 最小桌面可用。纸色、墨色、朱砂、荧光黄、4／8px 圆角与硬投影以 DESIGN.md 为准。旧搜索遮罩的蓝色不复制，改用纸感墨色遮罩；结果条目取消本票尚未接入的按钮悬停行为，记录差异。
