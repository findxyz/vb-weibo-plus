# 28：chat 历史采集（同步更早消息）

**What to build:** 在聊天记录窗口中按「同步历史至」日期调用本地采集接口，把更早的群消息拉入本地库；成功与失败都有明确提示，采集不改变当前会话。

**Blocked by:** 27，已完成。

**Status:** resolved

日期：2026-10-18。用户要求继续。本票只做聊天记录窗口里的同步入口与提示，不自动刷新结果。

## 实施边界

- 聊天记录窗口筛选栏增加「同步历史至」日期（默认 24 个月前，上海时区）与「⬇️ 同步历史」按钮。
- 点击后以 `POST /chat/since?gid&sinceTime` 提交，`sinceTime` 为 `YYYY-MM-DD 00:00:00`；不传 `beforeMid`，由后端自己从本地边界向前采集。
- 未选日期时提示「请先选择要同步到的历史日期。」且不发请求；请求中按钮禁用并显示「同步中…」；成功提示「已开始同步更早的历史消息，稍后请手动刷新查看。」；失败提示「同步历史请求失败，请稍后重试。」。
- 与旧页一致：发起同步时隐藏当前结果与上下文，成功或失败后由用户自行重新查询；不自动刷新、不乐观插入。
- 同一时刻只允许一个同步请求；关闭窗口或切群会中止请求；错误不影响消息展示。

- [x] 成功与失败分别显示对应文案，结果与上下文在同步期间隐藏。

### 实现

- `HistoryDialog.tsx` 增加「同步历史至」日期（默认 24 个月前，上海时区）与「⬇️ 同步历史」按钮；空日期提示「请先选择要同步到的历史日期。」且不发请求。

- Vite 代理补上 `/chat/since`；`api.ts` 增加不解析响应体的 `syncHistory`（后端返回 204）。
