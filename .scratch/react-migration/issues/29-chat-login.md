# 29：chat 扫码登录与失效提示

**What to build:** chat 页检测登录状态：失效时在群聊侧栏显示「登录已失效」与扫码入口，扫码成功后重新初始化群列表与消息；失效期间本地阅读继续可用，轮询暂停。

**Blocked by:** 28，已完成。

**Status:** resolved

日期：2026-10-18。用户要求继续。

## 实施边界

- 进入页面检测一次 `GET /weibo/login/status`；之后每 180 秒检测一次，页面隐藏或扫码中跳过；`valid === true` 才算有效。
- 失效时侧栏底部显示面板：失效文案、「📱 扫码登录」按钮；本地消息与群列表照常可读，但群列表与消息的每秒轮询暂停（与旧页 `authExpired` 一致），恢复后重新初始化。
- 扫码：点击按钮后禁用并显示「📱 扫码中…」，面板显示「正在获取二维码…」；`POST /weibo/login/qr`（最长 360 秒）期间，3 秒后首拉二维码图片，此后每 10 秒换新；图片加载失败时保留旧图或提示「二维码加载重试…」。
- 成功后隐藏面板、重新拉取群列表并重载当前群消息、恢复轮询，并再检测一次状态；失败时恢复按钮，保留最后一张二维码（没有图时显示「暂无二维码」），并提示「扫码登录失败，请重新扫码。」。
- 同一时刻只允许一个扫码请求；卸载或关页会中止请求并清理定时器。

### 实现

- `ChatPage.tsx` 进入页面检测 `GET /weibo/login/status`，之后每 180 秒检测一次；页面隐藏或扫码中跳过；只有 `valid === true` 才视为有效。
- 失效时侧栏底部（`GroupList` 的 `footer`）显示「登录已失效」「📱 扫码登录」面板；本地消息照常可读，同时暂停群列表与消息的每秒轮询（`refetchInterval: false`、`pollingEnabled=false`）。
- 扫码：`POST /weibo/login/qr`（最长 360 秒），期间按钮禁用并显示「📱 扫码中…」；3 秒后首拉 `/weibo/login/qr/image`，之后每 10 秒换新，图片经预加载成功后才替换；加载失败保留旧图或提示「二维码加载重试…」。
- 成功后隐藏面板、重新拉取群列表、重载当前群消息、恢复轮询并再检测一次状态；失败恢复按钮、保留最后一张二维码（没有图时显示「暂无二维码」）并提示「扫码登录失败，请重新扫码。」。
- 同一时刻只允许一个扫码请求；卸载时中止请求并清理定时器。
