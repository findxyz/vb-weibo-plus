# 怪兽回归庆祝接入聊天页

Type: feature
Status: resolved

## 问题

把原型演出接入真实回归庆祝：怪兽要用原型里的像素怪兽（MonsterDeleter 图集）戳破成员头像上的水泡，水泡与 UI 需符合聊天页现有风格，弃用原先四只 CSS 简笔怪兽。

## 结果

spawnCelebration 重写为原型剧情：怪兽从边缘走入（2.4 秒、8 帧/秒）→ 俯身轻戳两下（水泡果冻式晃动）→ 水泡胀裂、水珠飞溅、头像亮起 → 状态改「赶紧的一同拯救世界去」→ 怪兽举臂欢呼 → 雷欧赶到让怪兽原地骑上，骑稳后与成员卡片编队一同飞离舞台「去拯救地球」。台词是怪兽的话，悬在怪兽头顶：被包围期间「你终于冒泡了」（成员卡片此时上下微微浮动），戳破后当场改口「赶紧的一同拯救世界去」并随编队一同飞走。全程可点击怪兽跳过。

实现要点：

- 图集接入：走路、指泡、雷欧登场三段，LANCZOS 缩减为每帧 192 像素（540×576，共约 0.8 MB），存于 static/chat/assets/monster/，由 chat.js 的 Canvas 按帧时间轴选帧，卡片在左侧时水平镜像。雷欧图集前 5 帧为欢呼，5-9 帧雷欧入画，之后循环 10-14 帧骑乘飞行；独立的出场飞行图集因此弃用删除。
- 站位与朝向：图集怪兽面朝右，入场固定从面向的一侧进、沿面向的一侧出（镜像时相反），避免倒着走路；怪兽 220 像素、水泡 80 像素，站位偏移按指泡帧实测（指尖约在帧宽 95%、高 40% 处）反推，手指戳在泡缘且身体不挡头像。
- 泡破特效：径向渐变玻璃水泡、双高光、上下浮动与果冻晃动、胀裂消散、白色冲击环与 8 颗水珠飞溅，全部 CSS/WAAPI 实现，配色沿用聊天页令牌（--accent 蓝、--border-strong 药丸边框、--surface 白底）。
- 飞离编排：欢呼后 4.5-5.125 秒雷欧入画、怪兽在原地完成骑乘动作（图集 5-9 帧），5.125 秒起骑稳了才与成员卡片同时起飞、同速同向保持队形飞出（卡片终点 = 怪兽终点 + 起飞时卡片相对怪兽画布的偏移，同为 1.6 秒线性，全程队形不变，卡片带 5 度微倾）；终点沿两轴各留一整格余量，保证人马完全出画后才清理，动画结束统一清理。
- 弹层改动：四只 CSS 怪兽与选怪兽网格整体移除，改为「🎉 加入庆祝名单 / 👋 移出庆祝名单」按钮加间隔输入；按钮并入全页共享按钮规则（32px 高、继承字号、白蓝渐变），标签 13px、输入框 34px 高、提示 12px，与现有风格一致；旧名单数据里的 anim 字段保留但忽略。

验证：node --check 通过；预览页按状态截图核对（入场、轻戳、泡破欢呼含镜像站位、雷欧骑乘飞离），并放大核对指尖与水泡接触点；欢迎面板 hidden 修复确认生效。
