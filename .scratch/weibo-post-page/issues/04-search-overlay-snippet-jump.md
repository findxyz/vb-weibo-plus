# 04 - 高级搜索浮层与片段跳转高亮

**What to build:** 在 feed 头部右侧加「🔍 高级搜索」按钮，点击打开搜索浮层。浮层字段：关键词（必填）+ 起止日期（可选），搜索范围跟随当前选中博主（含「全部博主」时 uids 不传）。点搜索调用 `GET /post/list?keyword=...&start=...&end=...&uids=...&page=1&size=1000`，前端在命中的完整正文里找命中词位置、截取前后文、用 `<mark>` 包裹命中词生成片段（不新增后端 snippet）。结果在浮层内列表展示（每条显示日期+时间+片段），点击某条结果关闭浮层、自动选中日期树对应日、加载该日微博、`requestAnimationFrame` 后滚到该卡片并添加闪烁高亮 class（约 1.6s 后移除）。空结果显示「未找到匹配微博」，超 size 上限显示「已达上限（N 条），请缩小范围」。

**Blocked by:** 02 - 日期时间轴侧栏与按日加载（含后端 calendar 端点）
