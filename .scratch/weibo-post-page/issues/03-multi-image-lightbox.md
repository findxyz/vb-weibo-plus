# 03 - 多图灯箱翻页

**What to build:** 把现有单图图片查看器 `<dialog id="image-viewer">` 改造为支持多图翻页的灯箱：点击某条微博任一图片打开时，传入该微博的全部图片 URL 列表与当前索引，灯箱内可左右翻页浏览该微博的图片集合。翻页范围限定在单条微博内（本微博图片一组；转发原微博的图片算独立一组，不与本微博混合）。灯箱内显示计数器 `1/N`（N>1 时）、上一张/下一张按钮、加载占位，支持键盘左右键翻页与 Esc 关闭。

**Blocked by:** 02 - 日期时间轴侧栏与按日加载（含后端 calendar 端点）

**Status:** ready-for-agent

- [ ] 点击微博卡片任一图片后打开灯箱，传入该微博全部图片 URL 列表 + 当前索引
- [ ] 灯箱内显示计数器 `1/N`（仅 N>1 时显示）、上一张/下一张按钮
- [ ] 图片未载入时显示加载占位，载入后替换为图片
- [ ] 键盘 ← 翻上一张（非首张时）、→ 翻下一张（非末张时）、Esc 关闭
- [ ] 点击灯箱背景或图片关闭灯箱（沿用现有交互）
- [ ] 转发原微博的图片点击后在其自身图片集合内翻页，不与本微博图片混合
- [ ] 单图微博点击后灯箱不显示翻页按钮与计数器
- [ ] Playwright `PostPageTest` 覆盖：多图微博点击任一图打开灯箱、翻页、计数器、键盘翻页；转发图片独立分组；单图无翻页控件
