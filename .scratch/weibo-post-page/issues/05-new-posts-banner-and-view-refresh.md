# 05 - 新帖提示与 60 秒定时视图刷新

**What to build:** 前端每 60 秒执行一次定时视图刷新（不新增同步按钮/开关/倒计时圆环）：并行重拉 `/post/calendar`（刷新日期树计数与新增月份，已展开月份重新拉取日列表更新计数，保留展开态）与 `/post/list?start=当日00:00:00&end=当日23:59:59`（刷新当日微博）。当日微博刷新时与已渲染卡片 + 暂存待插入新帖做 id diff，发现新帖后暂存并显示「新增 N 条微博，点击查看」提示条（仅当前选中日期有新帖时显示）。点击提示条把暂存新帖插入到列表顶部并闪烁高亮、清空提示条。`await` 期间用户已切换日期则丢弃本次结果。搜索浮层打开时不刷新。

**Blocked by:** 02 - 日期时间轴侧栏与按日加载（含后端 calendar 端点）

**Status:** ready-for-agent

- [ ] 每 60 秒定时执行一次视图刷新：并行重拉 `/post/calendar` 与当日 `/post/list`
- [ ] 日期树刷新：已展开月份重新拉取日列表更新计数；新月份插入列表；保留当前展开态
- [ ] 当日微博刷新：与已渲染卡片 + 暂存新帖做 id diff，发现新帖后暂存
- [ ] 当前选中日期有新帖时显示「新增 N 条微博，点击查看」提示条（位于 feed 列表顶部）
- [ ] 点击提示条：暂存新帖插入列表顶部并闪烁高亮、清空提示条
- [ ] `await` 期间用户已切换日期则丢弃本次刷新结果
- [ ] 搜索浮层打开时不执行刷新
- [ ] 不新增同步按钮、轮询状态端点、自动刷新开关、倒计时圆环
- [ ] Playwright `PostPageTest` 覆盖：定时刷新触发新帖提示条、点击提示条插入并高亮、切换日期丢弃旧结果、搜索浮层打开时不刷新
