# 本地微博星空皮肤

以本次对话最后确认的效果图为视觉依据，仅调整 post 页面。群聊、后端接口和采集行为保持不变。

## 验收要求

- 顶部为微博标志与“随时随地发现新鲜事”，背景自然融入蓝色星空。
- 页面居中，左侧为连续深色微博流，右侧上方为星期一开头的方格日历，下方为博主管理。最小窗口为 900×560。
- 日历支持年份、月份直接选择与前后月导航；有内容的日期可点击，无内容的日期禁用。切换月份只导航，不触发读取或采集；切换博主回到最新有效日，搜索定位自动显示目标年月。
- 博主管理保留搜索、全部博主与添加功能；添加和同步历史并排。同步历史常驻，全部博主状态禁用，选中单个博主后可用；进行中的任务继续防止重复提交。
- 微博保留头像、认证、正文、转发、媒体、时间、地区、来源与查看原文；不增加评论、点赞、转发或收藏操作。
- 继续使用当前 post 页面的字体，正文为 15px／24px，转发为 14px／24px。
- 搜索、扫码恢复、历史采集、图片查看与群聊切换保持可用，弹窗随新皮肤更新。
- DESIGN.md 记录新的 post 专属令牌；新 ADR 替代 ADR-0006 的三栏日期树决策。

## 验证

沿用现有 Playwright 浏览器公共界面测试边界：用户点击、可访问名称与禁用状态、真实 HTTP 查询。新增日历与同步按钮回归；更新被本次设计替代的旧几何断言，不重录迁移基准。检查三档窗口、实际截图、类型检查和构建，最后运行前端全套测试。
